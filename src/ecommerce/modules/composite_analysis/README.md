# 综合选品分析

将同商品已有评价与问大家主报告整合为九章采购参考，入口为商品详情“综合分析”。报告来源、版本和实际输入固定；优先一次请求，超限才N组＋1汇总，费用确认与零自动重试沿用公共分析基础。

`store.py`负责候选和事务、`service.py`负责用例、`planner.py`负责消息容量、`runtime.py`负责固定计划执行、`report.py`负责本地检查与安全阅读。提示文件独立在`prompts`。不反向依赖Web，不启动基础分析或浏览器采集。

新增主提示语义时递增规则版本，改变引用检查语义时递增检查版本；历史正文及输入不转换。详情和已知限制见[实施记录](../../../../docs/变更记录/综合选品分析.md)。
