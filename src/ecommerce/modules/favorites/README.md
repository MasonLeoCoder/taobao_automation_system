# 长期商品关注

关注以商品内部编号唯一，保存加入时观察、来源词和备注；不复制商品字段，不调用采集。Web提供`/favorites`与受本机来源和页面令牌保护的`POST /api/favorites`，支持add/note/remove/undo。重复添加不覆盖旧记录，商品行锁串行化同商品写入，旧关注编号不能取消或修改重新关注后的记录。

持久表product_favorites来自0010/schema_v10；0001～0009及旧模型冻结。两条RESTRICT外键分别保护商品和加入时列表观察，事务额外校验观察属于商品且为已发布关键词来源。取消删除关注行；10秒内撤销使用服务签名的原记录，保留时间与备注，超时、错商品、篡改或已有新关注时拒绝；Web重启后旧撤销凭据失效，不影响数据库中已保存的关注。

独立页SQL分页20件，不限原200件；最近观察由窗口排序按采集时间/批次/观察编号降序，每页批量读取加入与最近行，图片仅匹配各观察自身位置。关键词筛选指加入时搜索词，店铺筛选/标题查询使用最近观察，商品编号用products身份。最近字段不借旧记录补齐，也不受分析页筛选影响；分析页则从同一表批量读取当前样本状态，未知身份禁用，原saved参数/sessionStorage不导入。

compare提示区分人数口径、近似/缺失和价格条件；数据状态按最近采集时间与关注时间比较，从历史观察关注但已有更新资料时不误称关注后新采集。不计算新增销量或机会评分。无关注导出或自动采集。对应验证见tests/unit/test_favorites.py、test_search_analysis.py、tests/integration/test_mysql_favorites.py和test_search_analysis_browser.py。
