提取按输入和原子观点输出保守分组，不固定10条、原文不截断；预留最多每组一次分段报告及一次总报告，能完整纳入时直接总报告，未用额度不调用。过长输入/单条或总报告超边界时保存已有内容并停在明确状态，不自动重试/提高上限/切换模型。总报告若基于分段发现筛选原文，明确显示所引/全部观点覆盖，未引用不代表不存在。

结果reviews-detail-v4保存原提取、字段疑点、派生资格；reviews-report-v4保存当时提取快照、全量程序倾向统计、报告覆盖、诊断及待复核候选。提取完成/报告生成/人工复核分开。原AI自由资料编号不作程序来源，观点集合重复只集中索引。人工修正保留原结果，另存修订和本地报告，旧AI推断不沿用；历史报告按自身快照展示。

analysis_review_store任务行锁校验当前报告、明细版本、归属、来源/候选哈希及决定序号。决定pending/adopted/rejected追加写，采用须明确核对依据，方向另须确认动作/条件和stop_scope；填写人是本机声明，不是账户认证。报告更新默认重新复核，不跨版本自动继承决定。保存决定只写新表，报告原JSON不改；读取派生复核状态与历史分开。Web/CLI查询、导出、recover、recount均不调用AI。新Web和旧CLI共用service，真实付费验收仍待明确授权。
