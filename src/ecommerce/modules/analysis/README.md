# 搜索词样本分析

2026-10-28：接入本机工作台 `/analysis/searches`，读取已发布、明确为关键词搜索的列表记录。无数据库迁移，不写入分析结果，不启动真实采集。

输入为搜索词、单次任务/独立批次或日期范围、标题初分类型、广告排除及明细筛选；输出为样本概况、价格分布、同口径数量散点、价格段交叉表、店铺分布、分页商品及CSV。数据库不可用返回明确错误，不伪造空数据；无效筛选400，快照不属于所选词/日期或页码越界404。

`service.analysis_page` 是共用业务入口；`infrastructure.storage.search_analysis` 只读批次和观察；Web仅处理输入输出、图形展示及当前浏览器标签页关注。

- 单次任务每件商品取首次完整观察；日期范围每件商品取最新完整观察。身份未确认按观察分别保留，先选观察再排广告，不用旧记录补位。
- 价格区间左闭右开：`[0,5)`、`[5,10)`、`[10,20)`、`[20,30)`、`[30,50)`、`[50,+∞)`。中位数及四分位数使用线性插值；未确认的非人民币价格不进入人民币分布。
- 数量按 `sales_metric + sales_period` 分组，标记精确、下界及近似，缺失不补0。达到1万的判断仅使用精确值和已达到门槛的下界；低于门槛的下界、近似值不进入可判断分母。图表使用 `log10(1+数量)` 保留零值，超过1000项时仅散点绘制前1000项并提示，统计不截断。
- 优先使用受信任平台公开店铺路由；缺少时按名称近似分组并提示，不将样本占比称为市场份额。
- 类型仅按标题初分，冲突或信息不足保留待分类；关注仅存当前标签页 `sessionStorage`，不新增数据库表。

用法、核对实例和限制见[搜索词分析首版实施记录](../../../../docs/变更记录/搜索词分析首版实施记录.md)。经营流量、推广、真实利润和市场销量趋势仍待实现。
