# 搜索词样本分析

2026-10-28：接入本机工作台 `/analysis/searches`，读取已发布、明确为关键词搜索的列表记录。无数据库迁移，不写入分析结果，不启动真实采集。默认日期范围汇总，每件商品取最新观察；日期留空汇总全部历史，与搜索列表商品汇总保持一致。

输入为搜索词、单次任务/独立批次或日期范围、广告排除及明细筛选；输出为样本概况、价格分布、同口径数量散点、价格段交叉表、店铺分布、分页商品及CSV。数据库不可用返回明确错误，不伪造空数据；无效筛选400，快照不属于所选词/日期或页码越界404。

`service.analysis_page` 是共用业务入口；`infrastructure.storage.search_analysis` 只读批次和观察；Web仅处理输入输出、图形展示及当前浏览器标签页关注。

`composition.price_composition`提供价位内展示档位和合计，精确值/下界/近似分开，色标在表内统一；`quantity_tier=指标:周期:精度:展示整数`仅是明细筛选参数，不写入数据库。构成表档位筛选限有效价格样本，图表和表格统计仍使用完整范围；旧`price_cross`门槛统计保留供原统计兼容，构成表已不展示固定1万达标率。

`composition.quantity_tiers`统一生成展示档位；`common_received_tiers`固定使用`received_people:last_30_days`，从完整筛选样本取最高商品数的全部并列档位，占比以该口径可用商品为分母，缺价亦计入。卡片点击使用`finding=quantity`配合`quantity_tier`，明确不限制价格，缺少档位返回400；原表链接不带此finding，继续限定有效价格。明细查询、分页、CSV和清除筛选复用原机制，旧`finding=high`链接兼容保留。

`regions.parse_location`只读归类列表`location_text`，省级全称、标准简称加分隔符及直辖市统一；不从单独城市推断省份，空值与明确未记录标记归`missing`，非空无法归属或复合省份归`unrecognized`。城市仅合并明确的“市”后缀，自治州/地区原名保留，省内城市无法识别单列`unrecognized`，原文字段不改写。只认识省份而无城市则为城市`missing`；直辖市按同名城市汇总。派生结构只在内存中存在，无数据库字段/JSON版本变化。

`shipping_distribution`使用广告筛选后的完整去重商品，省份分母为全部商品，城市分母为省内商品；已记录数为非missing数，包含待识别原文。`region`接受登记的省份简称或`missing/unrecognized`，`city`必须同时指定已登记省份，接受对应展示城市或城市`missing/unrecognized`；无效输入400，无当前匹配数据时为空明细。地区只影响明细/店铺/CSV，不缩小其他图表和地区分布自身；地区查看动作清理其他明细限制，其他价格/人数档位钻取清理地区。条件在表单和分页中沿用，CSV仅有地区筛选时附加元信息，原数据列保持不变。

`concentration.competition_concentration`从既有完整去重/广告筛选结果生成独立前50候选：身份、有效人数、近30天收货口径、非近似四类排除原因互斥计数。用整数排序，以页码/slot_index升序、采集时间降序、观察ID升序稳定处理同值，缺失位置在后；取前50后才用该名单合计计算CR3/CR10和HHI，Decimal保留中间精度。精确/下界均直接使用数值，零保留，无效人数不从旧观察补位。合计0无比值，不足3/10件对应CR无值，HHI参照10000/N；边界同值提示分列候选数、选入数、排除数。

`finding=top3/top10/top50`限定已计算的名单，前三/前十不足时为空明细，前50允许不足50；`sort=concentration`按计算顺序。查询/分页/店铺/CSV沿用条件，图表、地区统计及集中度自身保持完整范围；重新选择价格、档位或地区会清理旧名单，非名单请求的concentration排序回退position。模板`search_concentration.html`独立展示默认折叠的指标与依据，数值格式化由Web辅助函数处理，口径和筛选规则不放模板。无数据库、原始JSON或CSV数据列变更。

- 单次任务每件商品取首次完整观察；日期范围每件商品取最新完整观察。身份未确认按观察分别保留，先选观察再排广告，不用旧记录补位。

腰部指标的通俗名称及解释统一在Web模板metric_help_definitions.html维护，卡片/对照表调用公共help_label；悬停/键盘/触屏行为由help_tooltip.js处理。Web的_stat_money仅将腰部价格统计显示两位，_compact_number将人数统计显示最多两位并去除末尾0；原业务Decimal、商品_money和CSV数值均不变。解释文案不进入本业务模块或数据库。

`middle.middle_performance`只接收集中度结果，固定使用members[:10]作头部、members[10:30]作腰部，不重排或补样。整数/Decimal计算人数合计、单件均值、中位数和占前50比例，价格四分位数复用prices.quantile线性插值，各组有效人民币价格独立作分母。已知店铺以既有shop_key分组，头腰交集比例分母为腰部已知店铺数，缺失店铺及时间单列。边界使用完整有效候选的tie_count说明，档位精度不合并。

`finding=middle/middle_shared/middle_boundary10/middle_boundary30`分别选择腰部、腰部重合店铺商品及边界全部同值；后者通过`ranked_concentration_candidates`复用候选与排序，可包含前50之外的同值商品。中部档位筛选不要求有效价格，保留缺价商品；sort=concentration沿用原计算顺序，查询/分页不改变独立摘要。Web导出额外说明腰部及头部统计、价格覆盖、重合分母、时间和排序，原数据列不变；独立模板search_middle.html复用折叠、指标及数据标签样式，不产生持久数据或评分。
- 价格由`prices.price_distribution`按完整样本自动分段，尾部单列、同价合并，所有有效价格各有唯一归属；中位数及四分位数使用线性插值，明确非人民币价格不进入人民币分布。
