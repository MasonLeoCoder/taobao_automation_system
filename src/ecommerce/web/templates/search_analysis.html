分析口径与数据覆盖

原始范围 {{ stats.source_observations }} 条观察；当前筛选保留 {{ stats.products }} 项商品或身份未确认的独立记录。入口价覆盖 {{ stats.prices }} 项，数量覆盖 {{ stats.quantities }} 项。

  1. 先确定商品观察，再排除广告。单次任务取首次观察；日期范围汇总取最新观察。已识别广告被排除后，不用该商品旧记录补位。未命中广告标识不等于非广告。
  2. 入口价只用于初步比较。不同SKU、优惠条件和套装不可直接认定为同规格。
  3. 数量口径、周期和精度分别解释。未知数值不补0；精确展示、下界及近似分别标注；不计算真实总销量或销售额。零值保留在图中，近似值不参与1万门槛判断。
  4. 店铺分组保留识别依据。优先使用可信平台公开路由中的身份；缺少时按店铺名称近似分组。同名店铺可能不同，缺少店铺名称的记录不计入店铺分组。
  5. 所有统计反映当前采集样本。销量排序、采集页数和每页上限都会影响样本。展示次数不是曝光量；没有在本次结果中出现不代表商品下架。
  6. 关注仅保存在当前浏览器标签页。分析结果不写数据库；CSV导出包含当前筛选条件，不受网页分页截断。

自动价格分段

有效价格不超过6种时按实际价位分组；其他样本按当前价格范围生成约5～7段。用下四分位数减1.5倍四分位距、上四分位数加1.5倍四分位距识别尾部，尾部商品单列且保留。主体通常左闭右开，最后一段包含上限；尾部和同价组的精确边界见柱形提示。所有段商品数合计等于有效价格商品数，零元保留，缺失或明确非人民币价格不参与分段。并列最高段如实说明，不据此判断最佳定价或利润。
