## 以后如何维护

- 新文档按用途放入对应目录，并登记本索引；文首写用途、状态及适用版本或快照时点。
- 当前进度只更新验收清单；方案和报告保存当时事实，不能把程序完成改成人工通过。
- 字段及业务取值变化同步维护取值说明；结构和关联变化还须维护原生中文备注、字段字典与关系说明。
- 移动文件或修改标题时，同步引用、模块README和生成器内路径/锚点，交付前检查链接与字段覆盖。
