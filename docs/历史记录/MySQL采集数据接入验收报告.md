## 3. 一致性与异常处理

历史备份同时持有两平台浏览器资源锁，避免扫描过程中混入采集变动。固定清单核对原文件、备份文件和规范快照的哈希与大小；整批导入、逐字段重读通过后才提交发布。相同清单重复导入返回同一导入批次，同一来源键异文则整批回滚，保留失败原因。

实时采集保留原导出，先把规范快照和操作写入本地持久流水，后台只执行幂等数据库写入；采集资料和对应事件在同一任务行锁事务提交。下一平台检查点等待采集存储确认，结束记录位于采集操作之后。提交回执丢失可安全补写，不重放点击或其他浏览器动作。

完整结果才更新对应范围的有效分区；历史导入不能回退新的实时结果。缺失文件标记 missing，相关批次隔离；商品、任务、运行、步骤和媒体归属冲突以及派生循环均拒绝保存。无法重试解决的内容错误转为需要人工核对，保留本地现场。

补测发现并修复 Playwright 同步事件回调不继承 ContextVar 的任务关联问题：同一执行线程内回调仍归当前任务，嵌套退出恢复原绑定，其他线程不继承当前任务。人工决定后原动作执行一次。
