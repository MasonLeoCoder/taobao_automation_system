## 图片、入口参数和缺失项

- 共有 6 个 `img` 节点、4 个不同图片地址：主图与广告标识各有显示/隐藏副本，另外两种是标题图标和客服图标；只有 1 个不同的商品主图地址。
- 图片切换区有 5 个交互单元和 5 个指示点，但本片段没有其他 4 张主图地址，不能据此导出“已提取 5 张主图”。
- 商品入口的嵌套参数含 `skuId=6001949700618`，只能记为链接参数线索，不能据此确认当前规格、库存或完整 SKU 列表；是否保留该参数尚待用户确认。
- 店铺 `<a class="shopName--...">` 没有 `href`，因此店铺链接缺失，不从店铺名称猜地址。
- 本片段未给出明确的销量数字、原价、优惠金额、评论数量、独立品牌字段、完整 SKU 规格与库存。

- 外层存在商品 `<a>` 内嵌店铺 `<a>` 的结构。后续若解析 HTML 字符串，应确认解析器是否自动调整嵌套；单商品边界优先讨论外层 `div.search-content-col`，字段规则与解析方式仍待讨论确认。

## 新版正式实施规则

用户最终确认后，`cards.py` 已改为在浏览器中一次读取列表格子及字段，不对导出的 HTML 字符串再次解析，避免嵌套 `<a>` 被解析器重排导致店铺归错商品。

- 列表必须唯一匹配 `#content_items_wrapper`，遍历实际渲染的直接子格子。`slot_index` 保存原始 DOM 格子序号，`product_index` 为有效商品的连续序号。
- 商品格子需有唯一 `a#item_id_数字` 入口、可确认的商品 ID、完整标题和展示价格。ID 冲突、必要字段缺失或范围内存在未知类型时暂停，保存诊断记录，不静默略过。
- 标题优先读取 `title` 属性；主图只取显示主图区 `mainPic--`；价格、条件、销量原文、店铺、地区、榜单、属性/服务标签、图标地址和视频标识分别读取。
- 视频图标地址与视频文件地址分列；播放图标不当视频文件。SKU 参数单列为线索，不解释为实际规格或库存。
- 店铺链接仅保留公开路由必需的 `appUid`、`topIds`，去掉 `spm` 等跟踪参数。缺少或无法识别时标明状态，浏览器操作日志仍不记录完整查询参数。
- CSV 的“字段状态说明”区分“页面未提供”“元素或内容未识别”“不适用”；JSON `field_states` 同时保存逐字段状态。正常缺少榜单、价格条件等可选字段不阻止导出。
- 调查卡不输出商品行、不占数量上限、不操作评分。广告只标注不剔除；同商品 ID 在多个位置出现时逐位置保留，不合并，记录重复 ID 的额外展示位数量。
- “大家都在搜”推荐词卡需同时匹配 `suggestItemCard--` 结构、可见标题且没有商品入口，归为 `search_suggestions`，跳过且不占商品数量，不点击推荐词；混合结构仍记为未知。
- JSON `counts` 记录格子、商品、调查、推荐词卡、未知、破损商品和导出广告数量。格子数等于商品格子数加调查卡数加推荐词卡数加未知格子数，破损商品和广告都是商品子集。
- 默认 `limit=None`，采集当前页已加载的全部有效商品，不设固定 50 件上限；显式传入正整数才截取。不限量时整页未知或破损卡片均会暂停；有上限时，上限之后的未知格子仍记入批次 `issues`，不把有限导出描述成全页解析成功。
- JSON 不限量时 `requested_limit=null`，正常采完当前页记为 `all_loaded_cards_collected`，明确无结果仍记为 `empty`。
- 读取后及截图后复核关键词、页码、销量排序和列表内容。变化需人工核对并明确继续，重新读取当前页，不重搜、不重复点击排序。
- 新 JSON 使用 `schema_version=2`、`extraction_method=content_items_wrapper_slots_v1`。每批生成新 CSV/JSON，旧批次不覆盖。
- 真实页面首屏外的显示主图区采用延迟渲染。新增 `loading.py` 在同一页按视口分段滚动并使用 `scroll` 间隔，最多 8 次滚动和 4 次短等待，让范围内主图进入 DOM 后再取 `mainPic--`；不以隐藏 JPG 地址猜测显示 WebP 地址。JSON `image_loading`、`scroll_performed` 如实记录，未取得字段仍明确标记。
- 视频悬浮预览可能将静态 `mainPicAdaptWrapper--` 临时隐藏。只要已确认的主图结构存在，就读取其 `mainPic--` 链接，不因瞬时可见性丢弃，也不改取 `imageSwitch--` 的 JPG。固定测试覆盖这种情形及卡片只露边而尚未达到懒加载阈值的情形。
