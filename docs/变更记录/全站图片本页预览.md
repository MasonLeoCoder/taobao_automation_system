# 全站图片本页预览

2026-10-25，用户确认方案并明确执行：Web图片点击后在本页放大，再次点击恢复；补充遮罩、原位置恢复、加载失败提示、原图入口和放大镜指针。

## 实现与操作

公共base模板加载独立的image_preview.js与原生dialog。商品缩略图、搜索汇总、采集列表、SKU、主图和详情图等页面使用同一预览入口；动态加入的图片也可使用。没有新增第三方依赖或图片插件。

图片点击只打开预览；纯图片链接支持Enter/空格。商品详情列表把图片链接与商品标题链接分开，标题仍进入商品资料页。图片原链接在脚本未运行时继续保留作为原件入口。

预览使用原有图片源，保持比例、不裁剪，大图适应可用屏幕，小图不超过原始尺寸。加载期间显示提示，失败时显示原因，不显示空白图片。鼠标点击放大图片、空白区域、关闭按钮或按Esc均关闭。

打开时记录滚动坐标、原焦点及被修改的body内联样式，并锁定背景滚动；关闭后恢复。网页地址、筛选、排序及页码不变。“打开原图”是预览内单独入口，只有主动点击该入口才打开新标签。采集人工提示出现时，图片预览退出并让人工提示优先，避免挡住处理操作。

未增加滚轮缩放、拖拽、左右切图。既有采集、视频控件及数据查询不因预览触发写操作。
