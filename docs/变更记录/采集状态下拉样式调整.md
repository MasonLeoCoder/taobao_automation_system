# 采集状态下拉样式调整

2026-10-27，用户要求美化采集任务状态下拉框。本轮只修改该区域CSS，不改变筛选、分页、采集和数据库规则。

收起按钮采用44像素高度、圆角浅绿边框、统一箭头和柔和焦点光圈；展开菜单采用圆角、留白及阴影，选中项显示浅绿色底色、墨绿色文字和勾选，悬停及键盘焦点清晰可见。上下展开均保留间距，手机不横向溢出，减少动态效果设置下关闭过渡。

继续使用原select及option，浏览器支持时通过appearance:base-select美化展开菜单；不支持时回退原生菜单，收起框保持统一样式。不新增自制菜单或JavaScript控制逻辑。实现参考[Chrome官方说明](https://developer.chrome.com/blog/a-customizable-select)，本机验证Chromium149支持所需CSS；未宣称所有旧浏览器的展开菜单外观相同。

4项既有隔离浏览器分页/状态切换/刷新/手机布局用例通过。正式网页只读核对收起与展开截图、键盘选择、Escape取消、点击外部关闭及390像素布局；禁止POST和外部请求，未启动真实采集。截图及日志位于workspace/output/reports/collection_filter_style_20261027/。不涉及表结构、字段取值或原39项真实平台验收变化。
