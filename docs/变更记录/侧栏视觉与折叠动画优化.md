# 侧栏视觉与折叠动画优化

2026-11-03。范围为已批准的左侧菜单美化与动画；六组分类、十个已有入口、21个规划页、原业务操作和展开记忆保持。人工视觉与动画体验待用户确认。

## 展示与交互

- 延续墨绿风格，六组标题增加线条SVG图标；统一标题间距、圆角、箭头、二级缩进与细引导线。
- 当前分组保留浅绿提示，当前子页面增加细色条；待建设标记弱化。收起当前分组后显示当前子页面名称，展开时平滑隐藏。
- 分组与手机功能导航采用240毫秒高度、透明度动画，箭头同步旋转；快速反向点击从当前实际高度衔接，旧动画不能覆盖新决定。
- 关闭动画过程中暂保留原生open绘制，通过inert立即排除子项交互与焦点，动画完成再收起。键盘Enter、Space沿用原生summary激活；无JavaScript时仍可使用原生details。
- 本浏览器仍记忆分组展开状态；刷新后当前组自动展开。浏览器存储不可用时本页仍可操作；手机/桌面切换复用原有展开策略。
- 品牌与店铺区固定，长菜单在侧栏内部滚动；滚动条在悬停或焦点进入时显示。系统减少动态效果时直接切换，过渡及运行中的动画简化。

## 实现边界

模板和脚本仅维护菜单外观状态，不发起业务请求。图标及箭头复用公共控件宏，颜色、字体、交互外观与动效参数集中在form_controls.css，workspace.css仅负责侧栏布局；无新依赖、数据库字段、迁移、业务任务或AI请求。

## 使用

CMD项目根目录执行 `.venv\Scripts\python.exe main.py web --port 8000`，打开 `http://127.0.0.1:8000/`。已有服务更新后需重启以加载模板，浏览器Ctrl+F5刷新。点击组名展开或收起，手机先展开“功能导航”。不增加参数或业务配置。
