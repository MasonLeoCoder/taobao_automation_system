# 菜单配置数据库化

2026-11-03。用户批准两表配置、固定路由、两级显示/启用和建设状态独立。本轮已将6分组31菜单初始化到正式库及验证库，不新增经营账本等规划业务，不启动真实采集、AI或商品提交。两库均为0025_web_menu，网页使用原8000端口。

## 修改入口

正式库：`taobao_automation`。打开数据库工具中的`web_menu_groups`和`web_menu_items`，可以直接修改并保存名称、顺序、是否启用、是否显示；菜单还可以修改所属group_key。提交后刷新网页，或发起下一次请求即可生效，无需重启服务。

固定group_key/menu_key关联程序图标、路由和展开记忆，日常不修改；construction_status是程序实际建设状态，不用于手动开放规划能力。页面或服务启动不补写默认值，升级不覆盖人工配置。规划页名称与面包屑随菜单修改，规划正文及已有业务页面内容保留。

## 查询与修改示例

以下是按需手动执行的示例，本轮迁移不会替你改名、隐藏或停用任何菜单。数据库工具会话统一设置北京时间；每次仅选择需要的UPDATE，保存/提交后刷新网页。

```sql
USE taobao_automation;
SET SESSION time_zone = '+08:00';

SELECT group_key, name, sort_order, is_enabled, is_visible, updated_at
FROM web_menu_groups ORDER BY sort_order, group_key;

SELECT menu_key, name, group_key, sort_order, construction_status,
       is_enabled, is_visible, updated_at
FROM web_menu_items ORDER BY group_key, sort_order, menu_key;
```

按需修改名称：

```sql
UPDATE web_menu_items SET name = '收支管理' WHERE menu_key = 'ledger';
```

按需调整顺序或移动到另一组（分组固定标识见查询结果）：

```sql
UPDATE web_menu_items SET sort_order = 5 WHERE menu_key = 'ledger';
UPDATE web_menu_items SET group_key = 'research' WHERE menu_key = 'ledger';
```

隐藏／重新展示（只改变侧栏）：

```sql
UPDATE web_menu_items SET is_visible = 0 WHERE menu_key = 'ledger';
UPDATE web_menu_items SET is_visible = 1 WHERE menu_key = 'ledger';
```

停用／恢复（影响直接访问和新操作）：

```sql
UPDATE web_menu_items SET is_enabled = 0 WHERE menu_key = 'ledger';
UPDATE web_menu_items SET is_enabled = 1 WHERE menu_key = 'ledger';
```

分组名称、排序和开关同理操作`web_menu_groups`；组内子项保留自己的设置。上述UPDATE适用于自动提交会话；关闭自动提交时须手动COMMIT。updated_at由MySQL实际修改时自动更新，不必手填。恢复开关使用UPDATE，不通过删行恢复默认值。

## 状态与路由

| 有效状态 | 侧栏 | 直接链接与原功能操作 |
|---|---|---|
| 启用＋显示 | 展示 | 按原功能规则执行 |
| 启用＋隐藏 | 隐藏 | 仍可访问，不是权限关闭 |
| 停用 | 隐藏 | 页面/新操作返回403，提示功能已停用 |

分组停用优先于子项；分组隐藏仅影响展示；无可展示项时整组隐藏。排序同值按固定标识，保证稳定。建设状态available表示原功能已接入，planned表示仍是规划页；Web会核对其与程序一致，改开关不生成业务功能。

数据库不保存任意路由字符串，仍由程序固定映射。例如ledger始终指向`/plans/ledger`，catalog指向商品库及相关详情/分析功能。改名和移动不改变旧地址。停用覆盖子页面、接口、导出和新任务动作；共享批次/素材按实际已发布来源判定归属。列表缩略图也用于已启用的搜索词分析、我的关注及商品库，允许这些页面读取共享图片，不因此开放停用的列表/详情数据。通用商品采集入口归collection，商品页新采集同时受catalog控制。

必要任务状态及明确暂停/停止通道不被菜单关闭阻断，原安全校验继续生效；既有运行不自动终止，恢复/继续/重试不是例外。Web配置不改变CLI功能。静态资源与健康检查不依赖菜单配置。

配置读取失败、缺项、未登记标识或建设状态冲突时返回503，不能静默用旧默认值重新开放。可直接在数据库核对、修复后刷新；错误提示不包含凭据。兼容的非MySQL启动模式继续使用固定目录，正式MySQL失败不会切换该模式。
