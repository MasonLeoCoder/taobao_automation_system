# 工作台功能规划与菜单整理

2026-11-03。范围：六组菜单、21个静态规划页与原有十个入口归类。新增业务功能尚未建设；本轮不修改数据库、采集、AI分析、商品提交或经营数据。人工体验待确认。

## 菜单结构

| 分组 | 原有入口（地址与操作保留） | 待建设规划页 |
|---|---|---|
| 经营工作台 | 工作台概览 | 经营档案、AI经营助手、经营日历、提醒中心、经营知识库 |
| 市场与选品 | 商品采集、搜索列表、商品库、搜索词分析、我的关注 | 选品项目、采购与拿样、成本与利润测算 |
| 我的商品 | 千牛命令行能力保持原使用方式 | 商品档案、商品策划与上架、定价与促销、素材资产库 |
| 店铺经营 | — | 经营数据、经营诊断、推广与优化、经营账本 |
| 交易与履约 | — | 订单与异常、库存与补货、售后与反馈 |
| 工具与系统 | 工具箱、任务记录、运行日志、AI设置 | 数据接入、备份与恢复 |

菜单分组可展开和收起，本浏览器记忆分组展开状态；进入页面后当前分组自动展开，当前入口唯一高亮。桌面侧栏内部滚动，手机使用“功能导航”展开菜单；无脚本或浏览器存储不可用时仍可通过原生菜单访问。浏览器仅保存菜单外观状态，不保存经营资料或付费授权。

## 规划内容归并

- 经营档案：店铺背景、经营目标、供货方式、预算与约束。
- AI经营助手：结合资料咨询、行动计划、待办、完成标准与执行复盘。
- 经营日历：上新、询价、拿样、采购、活动及复盘的时间安排。
- 提醒中心：异常、待确认问题、处理进度与结果。
- 经营知识库：选品标准、拿样检查、供应商经验、话术与案例。
- 选品项目：研究方向、竞品报告、多商品比较、候选阶段与决策理由。
- 采购与拿样：供应商、询价、供货条件、样品测试及采购判断。
- 成本与利润测算：预计成本、价格与推广情景、投入前的判断依据。
- 商品档案：自有商品、SKU、货源、成本、参考竞品、资料版本及经营阶段。
- 商品策划与上架：商品方案、规格组合、卖点、内容策划及上架准备。
- 定价与促销：售价、优惠、活动方案及后续表现。
- 素材资产库：自有及供应商图片、视频、文案、来源和版本。
- 经营数据：自己店铺的流量、点击、加购、成交、退款及数据周期。
- 经营诊断：经营问题、依据、资料缺口、优先动作。
- 推广与优化：推广方案、商品调整、实验与效果复盘。
- 经营账本：手动登记进货、投流、其他支出、收入与退款，按时间、分类和商品汇总。
- 订单与异常：订单、履约状态、异常跟进。
- 库存与补货：期初库存、出入库、采购到货及补货关注项。
- 售后与反馈：退款原因、买家反馈、商品和规格归属、采购及页面改进。
- 数据接入：手动资料、表格导入、来源与时间范围核对。
- 备份与恢复：保护范围、备份记录及恢复核对，不执行历史数据恢复。

## 页面约定与能力边界

每个新页面展示“待建设”、准备解决的问题、计划提供的帮助、需要准备的资料以及真实已有入口。不放模拟经营数据、填写表单或假执行按钮。

商品库用于采集研究资料；商品档案用于自有经营商品。我的关注用于收藏；选品项目用于正式评估。成本与利润测算用于事前估算；经营账本用于实际收支，收支结余不能直接当经营利润，销售金额与到账款不能重复计算。搜索词分析是外部采集样本，不代表自己店铺数据。

评价、问大家、主图、详情图和交叉分析继续在原商品资料页内使用。千牛命令行的单商品Excel与素材填写保留；新的上架页面仅是网页工作流规划。

规划页面为GET/HEAD，未知标识返回404，POST返回405。静态定义在 `web/workspace_plan.py`，不接数据库或创建业务任务，不改 `shared/features.py` 的可执行能力状态。

## 建设顺序建议

先打通选品、拿样、事前测算及手动经营账本，再逐步补齐自有商品、上架、经营数据与日常履约。这里只记录建议，不承诺具体建设时间；每项实际开发前另行确定方案。
