# 网页采集配置入口说明

2026-10-26，按用户确认方案完成。入口沿用左侧“商品采集”（`/modules/collection`），不新增重复菜单。本轮为代码、文档与隔离验证；未启动真实淘宝采集，不代替人工平台验收。

## 页面操作

- 关键词采集：关键词、从第一页开始的页数、每页不限/正整数上限、是否连带九个详情模块。固定销量排序，当前页列表和详情确认后再翻页。
- 商品详情采集：任意商品 ID 或完整淘宝/天猫链接，九模块默认全选，支持单选、多选、全选/取消。评价默认100条、问大家默认50题，两个数量范围可独立设为不限，每题采集全部可见回答。
- 配置摘要随输入更新，点击开始直接派发后台任务；最近任务显示本次设置、已保存进度、日志、结果和停止入口。刷新及跨页面可恢复在途任务和人工提示。
- 商品页保留单模块采集、只补齐剩余模块；“重新采集／配置采集范围”带入当前商品和模块，重新采集保留历史。
- 长任务说明折叠展示，正常列表保留清晰状态；无效参数、未选模块、数据库不可用和任务冲突明确提示。

## 执行与结果规则

关键词及新商品详情复用既有统一执行器、淘宝浏览器资源锁和平台守卫，请求线程只做校验和派发。重复提交同一在途配置复用原任务，不同配置等待当前任务完成或停止；命令行淘宝任务同样参与资源互斥。

网页登录和原生弹窗通过既有定向反馈处理，继续必须经过平台页面复查。排队停止不会启动采集；执行中停止由检查点接收。网络中断不自动重放采集。配置页任务状态尚未读取成功时禁止启动。

仅接受本机来源与页面令牌，不把链接跟踪/授权参数保存到派发描述。新商品不依赖已有商品记录；有本次保存资料后才提供结果入口。结果核对绑定当前任务、商品、模块或列表批次，旧结果不能冒充本次成功。

不新增数据库表或列。采集仍按现有每页批次、商品入口、运行及九模块记录入库；评价/问大家独立参数只改变各自既有100/50或NULL数量范围。CLI `--all`继续兼容同时取消已选评价/问大家的上限。详细派发参数见[字段取值说明](../数据库字段取值说明.md#2026-10-26-网页配置采集入口)。
