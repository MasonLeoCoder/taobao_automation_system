# Cloudflare Tunnel（Windows 11 / PowerShell）命令速查

## 当前环境

| 项目 | 配置 |
|---|---|
| 操作系统 | Windows 11 |
| 终端 | PowerShell |
| cloudflared 文件 | `D:\cloudflared\cloudflared.exe` |
| 本地 Web 地址 | `http://localhost:8000` |
| 连接方式 | Cloudflare Quick Tunnel（临时公网地址） |

## 1. 进入程序目录

```powershell
cd D:\cloudflared
```

## 2. 查看版本

```powershell
.\cloudflared.exe --version
```

## 3. 启动内网穿透（常用）

在 `D:\cloudflared` 目录中：

```powershell
.\cloudflared.exe tunnel --url http://localhost:8000
```

**无需切换目录的完整命令：**

```powershell
D:\cloudflared\cloudflared.exe tunnel --url http://localhost:8000
```

运行成功后终端会显示一个形如 `https://随机名称.trycloudflare.com` 的地址。保持本地 Web 服务器与运行隧道的 PowerShell 窗口开启。

## 4. 停止内网穿透

在运行隧道的 PowerShell 窗口按 **Ctrl + C**。

## 5. 重新启动内网穿透

```powershell
D:\cloudflared\cloudflared.exe tunnel --url http://localhost:8000
```

> Quick Tunnel 重新启动后通常会生成新的随机公网地址。

## 6. 查看 cloudflared 进程

```powershell
Get-Process cloudflared
```

如果没有运行中的进程，可能会提示找不到进程。

## 7. 强制停止 cloudflared（谨慎使用）

```powershell
Stop-Process -Name cloudflared -Force
```

此命令可能停止多个同名进程；优先使用 **Ctrl + C**。

## 8. 检查本地 Web 服务

查看 HTTP 响应头：

```powershell
curl.exe -I http://localhost:8000
```

如果服务不支持 `HEAD` 请求，可以改用：

```powershell
curl.exe http://localhost:8000
```

## 9. 检查 TCP 8000 端口

```powershell
Get-NetTCPConnection -LocalPort 8000 -State Listen
```

用于确认本机是否有服务正在监听该端口。

## 日常操作流程

1. 启动本地 Web 服务，并确认 `http://localhost:8000` 可访问。
2. 打开 PowerShell，运行：

   ```powershell
   D:\cloudflared\cloudflared.exe tunnel --url http://localhost:8000
   ```

3. 复制终端生成的 HTTPS 公网地址。
4. 使用手机移动网络测试公网访问。
5. 不再需要时，在运行隧道的窗口按 **Ctrl + C**。

## 注意事项

- Quick Tunnel 适合临时测试；公网网址不固定，也没有长期在线保证。
- 电脑、本地 Web 服务和 `cloudflared` 都需保持运行。
- 拿到公网地址的人可能访问该网站。请勿暴露未设身份验证的后台或敏感数据。
- 不要把 MySQL 3306 等数据库端口直接开放到互联网。
- 长期使用可考虑命名隧道、固定域名、开机自启及 Cloudflare Access 保护。
