# CMD 使用指南

先在 CMD 执行以下三行，进入项目并使用已有虚拟环境：

```cmd
set "TAOBAO_PROJECT=D:\VSCodeProject\taobao_automation_system"
cd /d "%TAOBAO_PROJECT%"
call "%TAOBAO_PROJECT%\.venv\Scripts\activate.bat"
```

## 命令可以执行什么

| CMD 命令 | 功能 |
|---|---|
| `python "%TAOBAO_PROJECT%\main.py" account login` | 登录千牛；需要时扫码，成功后保存登录状态 |
| `python "%TAOBAO_PROJECT%\main.py" account check` | 检查登录是否有效 |
| `python "%TAOBAO_PROJECT%\main.py" product open` | 打开商品发布入口；加下面的参数执行填写 |
| `python "%TAOBAO_PROJECT%\main.py" product open --keyword "粘毛器" --no-wait` | 仅复测发布入口和搜索，结束后关闭浏览器 |
| `python "%TAOBAO_PROJECT%\main.py" status` | 查看已实现和待实现功能 |
| `python "%TAOBAO_PROJECT%\main.py" tasks` | 查看最近 50 条任务记录 |
| `python "%TAOBAO_PROJECT%\main.py" web --port 8000` | 启动本地工作台，访问 http://127.0.0.1:8000 |
| `python "%TAOBAO_PROJECT%\main.py" product --help` | 查看商品命令帮助 |

## 参数代表什么

商品参数加在 `product open` 后面。文件和目录路径、带空格的文本都放在双引号中。

| 参数 | 含义 |
|---|---|
| `--keyword "粘毛器"` | 发布页搜索词 |
| `--category "完整类目路径"` | 用 `>` 分隔的完整类目；需要搜索词 |
| `--brand "无品牌/无注册商标"` | 选择品牌并进入填写页；需要类目 |
| `--main-images-dir "目录"` | 上传目录中的五张 1:1 主图 |
| `--portrait-images-dir "目录"` | 上传目录中的五张 3:4 主图 |
| `--detail-images-dir "目录"` | 按数字编号上传全部详情图 |
| `--video-file "文件.mp4"` | 上传商品视频，可省略 |
| `--product-info-file "文件.xlsx"` | 读取固定格式 Excel，填写分类、两个标题、五个属性、SKU、价格及编码；启用多件优惠，选择放入仓库 |
| `--sku-images-dir "目录"` | SKU图片目录，可省略；默认 Excel 同目录下的 `sku图`，需同时提供 Excel |
| `--submit` | 填写后点击提交到仓库；需要品牌及 Excel。不加时只填写 |
| `--no-wait` | 正常完成后自动关闭浏览器；中途人工提示仍会等待 |
| `--start` | 旧页面“开启”按钮兼容参数，尚未完成真实验证，正常流程不用 |
| `--port 8000` | 工作台端口，只用于 `web` 命令 |
| `--config "配置.toml"` | 指定配置文件，放在 `account`、`product` 等子命令之前 |

素材上传和 Excel 参数都需要先提供品牌，以进入商品填写页。Excel 使用现有固定格式的 `Sheet1`，运行前保存文件。

SKU 自动逐条填写：**SKU搜索主图、商品规格图片**共用同名图片（文件名去扩展名须等于完整销售规格名，扩展名不限）；**SKU搜索标题**使用 Excel 的“导购标题”。缺图、缺标题或未找到页面规格时，跳过对应字段并写明日志，其他可填字段继续；同名多图不猜选，页面已有图片保留并记录。

## 示例：填写 CJ004，不提交（主要针对【粘毛器】的类目）

已完成上面的路径设置后，复制整段执行：

```cmd
python main.py product open ^
  --keyword "粘毛器" ^
  --category "宠物/宠物食品及用品 > 猫/狗美容护理工具 > 粘毛器" ^
  --brand "无品牌/无注册商标" ^
  --main-images-dir "D:\VSCodeProject\taobao_automation_system\workspace\input\products\CJ004\1-1主图" ^
  --portrait-images-dir "D:\VSCodeProject\taobao_automation_system\workspace\input\products\CJ004\3-4主图" ^
  --detail-images-dir "D:\VSCodeProject\taobao_automation_system\workspace\input\products\CJ004\详情图" ^
  --video-file "D:\VSCodeProject\taobao_automation_system\workspace\input\products\CJ004\CJ004.mp4" ^
  --product-info-file "D:\VSCodeProject\taobao_automation_system\workspace\input\products\CJ004\产品信息.xlsx" ^
  --submit
```

- `^` 是 CMD 换行符，后面不要留空格。
- 以上命令只填写；需要提交到仓库时，在最后一行末尾加 ` --submit`。重复运行会重新进入发布流程。
- 最后按“回车关闭浏览器”的提示结束。

## 遇到弹窗怎么办

以上千牛命令已自动启用全局检测，无需增加参数；正常图片、视频、规格窗口按原流程使用。
主图、详情图和 SKU 图片上传期间会持续接管文件选择请求，防止额外的系统“打开文件”窗口；无需新增命令或参数。

| 提示 | 你的操作 |
|---|---|
| 已识别的“SKU管理页引导”公告 | 程序自动关闭；关闭失败则转人工 |
| 系统验证、未知弹窗或意外标签页 | 听到提示音后手动处理，在同一个 CMD 输入 `继续` 回车；没有反馈一直等待，弹窗仍在则继续等待 |
| 浏览器原生确认框 | 阅读终端中的内容，输入 `确认` 或 `取消` 回车；输入 `继续` 不会作出决定 |
| 当前等待或填写步骤超时 | 手动关闭弹窗后输入 `继续`，程序在当前浏览器恢复这个子步骤，完成后接着执行；已上传的素材不会重新上传 |
| 商品提交检查 | 人工核对页面和仓库后输入 `继续`，程序只复核结果，避免重复提交 |
